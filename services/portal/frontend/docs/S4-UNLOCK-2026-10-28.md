## 바뀐 동작

관리자 `/admin`에서 본인을 제외한 잠긴 계정 행에 **오탐 해제(비밀번호 유지)** 버튼이 나타난다. 확인창에서 계정 아이디·표시 이름과 잠김→해제·비밀번호 유지 내용을 확인한다. 새 비밀번호 입력은 없다. 오탐 확인 후 해제 버튼을 누르면 공통 API 클라이언트가 관리자 세션·CSRF로 `POST /api/v1/admin/users/{id}/unlock`, JSON `{"reason_code":"false_positive"}`를 보낸다.

응답의 대상 id·locked:false를 확인한 뒤 성공을 알리고 목록·검색 전체 집계를 서버에서 다시 조회한다. 잠김 필터에서 마지막 항목이 빠지면 기존 페이지 보정 로직을 사용한다. 요청 중 확인·취소·닫기를 막고 추가 form 제출을 무시한다. 거부/네트워크 실패/대상 불일치·여전히 잠김인 성공 형식 응답은 성공으로 표시하지 않는다. 오류 뒤 자동 재전송은 하지 않는다.

기존 비밀번호는 유지하고 기존 세션은 복원하지 않는다. 사용자는 새로 로그인해야 한다. 침해 의심 시 사용하는 기존 비밀번호 재설정 동작도 그대로 제공한다. 일반 이용 중 계정·본인 행에는 오탐 해제 버튼이 없다.
