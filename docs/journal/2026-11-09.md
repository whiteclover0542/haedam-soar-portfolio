## 문제: 검사 실패를 못 보고 push한 일

- **증상:** `secret_scan.py`(인자 없이 전체 검사)가 한글 파일명(`docs/MVP-설계.md`) 때문에 `UnicodeDecodeError`(cp949)로 멈췄다. 그런데 명령을 `;`로 이어 붙여서 `gh repo create … --push`가 그대로 실행됐다.
- **영향:** 비공개 저장소였고, 직전에 반입 폴더 전체를 이미 0건으로 검사한 상태라 노출은 없었다.
- **조치:**
  - `git ls-files` 출력을 바이트로 받아 UTF-8로 디코딩하도록 고쳤다.
  - 회귀 테스트 `test_default_mode_handles_korean_filenames`를 추가했다.
  - 저장소 전체가 깨끗한지 보는 `test_repo_is_clean`을 추가했다.
- **배운 점:** 외부로 내보내는 명령은 검사 명령 뒤에 `&&`로만 잇는다.
