# SOAR 시나리오 준비 카드

Docker를 실행하지 않아도 아래 카드를 읽고 발표·시연 데이터를 준비할 수 있다. 실제 실행과 효과 검증은 전체 MVP 모드에서만 한다.

| 카드 | 입력 신호 | 기대 조치 | 정상 사용자 확인 | 발표 기록 |
| --- | --- | --- | --- | --- |
| S1 | 같은 계정의 연속 로그인 실패 | 포털에서 공격 출발지 IP 차단 | 정상 출발지에서 로그인 유지 | 티켓 ID, 탐지 시각, 차단 코드 |
| S8 | 존재하지 않는 경로 탐색 뒤 로그인 시도 | 포털 IP 차단 | 정상 출발지의 포털 API 200 | 소스 IP, 로그 수, 응답 코드 |
| S10 | WAN ping·경로 탐색·실패 로그인 | pfSense와 포털의 다중 차단 | 정상 출발지의 포털 API 200 | 두 조치 결과, 차단·해제 시각 |

## 발표 전 점검

1. 시연 카드 하나를 고르고 공격 출발지·정상 출발지·예상 응답 코드를 기록한다.
2. 티켓 ID와 시작 시각을 빈칸으로 두고, 실행 뒤 채운다.
3. 효과 확인 뒤에만 해제를 실행한다. 해제 결과와 공격 출발지의 복구 응답도 기록한다.

## 기록 양식

```text
카드: S__
시작 시각: 
티켓 ID: 
탐지까지 걸린 시간: 
조치: portal / pfsense
공격 출발지 응답: 
정상 출발지 응답: 
해제 후 공격 출발지 응답: 
특이 사항: 
```
