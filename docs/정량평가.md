## 지표 정의

| 지표 | 정의 |
| --- | --- |
| 자동 대응 | 사람 개입 없이 기대한 차단(S10은 포털+pfSense, S8·S1은 포털)이 모두 적용되고, 공격자 거부(403 또는 연결 실패)와 `normal` 200이 함께 확인된 회차 |
| 원복 | `--restore` 해제 뒤 공격자 요청이 다시 200인 회차 / 원복 시도 |
| 정상 사용자 영향 | 대응 중 `normal`(`203.0.113.100`)의 요청이 200이 아니었던 회차 수 |
| MTTD | Graylog 이벤트의 조건 충족 시각(`event.timestamp`) → 탐지 처리 시각(`timestamp_processing`) |
| 탐지→차단 | 탐지 처리 시각 → 마지막 차단 조치 완료 |
| 입력→차단 | 실행기가 공격 입력을 시작한 시각 → 마지막 차단 조치 완료. Graylog 1분 평가 주기가 포함된 체감 시간 |

중앙값은 자동 대응에 성공한 회차만으로 계산합니다. 실패 회차도 표와 회차 수에는 남깁니다.
