# H1 민원 도배

- **작성:** A — 포털 작성 제한 API, 탐지 정의 `lab/h1/graylog/h1-petition-flood.json`, n8n `haedam-35`·`haedam-18`

## 시나리오

| 단계 | 내용 |
| --- | --- |
| 준비 | `normal`(`.100`)이 회차마다 새 계정 `zz_a_h1_<run_id>`를 가입시킨다 |
| 입력 | `203.0.113.11`이 그 계정으로 로그인해 민원 8건을 연달아 등록(201) |
| 탐지 | Graylog 정의 "H1 민원 도배 (username)": 10분 안 같은 `username`의 `petition.created` 5건 이상 |
| 대응 | n8n `haedam-35` → `haedam-18` 포털 작성 제한(그 계정만. IP 차단 아님) → 티켓 기록 |
| 효과 | 그 계정의 민원 작성 429, **로그인·목록 조회는 200 유지**, `normal` 작성 201 |
| 원복 | 담당자가 포털 대응 API로 해제 → 작성 201. 티켓은 `responding`에 두고 사람이 확인 후 닫는다 |

## 실행

```powershell
python lab/run_ticket.py H1 --restore
python lab/run_ticket.py H1 --baseline   # 정상 시민 속도(2분 간격 3건), 티켓이 없어야 pass
```
