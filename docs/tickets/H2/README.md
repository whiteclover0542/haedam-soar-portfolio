# H2 타인 민원 엿보기

- **대응 구성:** 탐지 정의 `lab/h2/graylog/h2-petition-access-denied.json`, n8n H2 대응(포털 계정 차단+잠금), 입력 준비 `lab/h2/input.py`

## 시나리오

| 단계 | 내용 |
| --- | --- |
| 준비 | `normal`(`.100`)이 회차마다 공격 계정 `zz_a_h2_<run_id>`를 가입시킨다 |
| 입력 | `203.0.113.11`이 그 계정으로 로그인해 `GET /api/v1/petitions/{id}`로 타인 민원 상세를 연달아 3건 조회 → 전부 403 |
| 탐지 | Graylog "H2 타인 민원 열람 반복 (username+src_ip)": 5분 안 같은 `username`+`src_ip`의 `petition.access_denied`(403) 3건 이상(count>2), 1분 평가 |
| 대응 | n8n → 포털 계정 차단+잠금(그 계정만. IP 차단 아님) → 티켓 기록 |
| 효과 | 그 계정의 민원 조회 403·로그인 401, `normal` 조회 200 유지 |
| 원복 | 담당자가 해제 → 계정 정상(200). 단 **타인 민원 조회는 여전히 403**(접근 권한은 원복과 무관) · 미인증 해제 시도는 403으로 거부 |

## 실행

```powershell
python lab/run_ticket.py H2 --restore
python lab/run_ticket.py H2 --baseline   # 정상 속도(타인 민원 거부 2건), 티켓이 없어야 pass
```
