# S1 로그인 무차별 대입

- **원작:** 반소람(A) — 탐지 정의 `lab/s1s4/graylog/s1-login-bruteforce.json`, 포털 대응 API

## 시나리오

| 단계 | 내용 |
| --- | --- |
| 준비 | `normal`(`.100`)이 회차마다 새 계정 `zz_a_s1_<run_id>`를 가입시킨다. 비밀번호는 실행기 메모리에만 있고 기록하지 않는다 |
| 입력 | `203.0.113.11`이 그 계정으로 틀린 비밀번호 로그인 9회(401) |
| 탐지 | Graylog 정의 "S1 로그인 무차별 대입": 30분 안에 같은 `username`+`src_ip`의 401이 8회 초과 |
| 대응 | n8n `haedam-30` → 포털 IP 차단(출발지만. 계정은 잠그지 않음) → 티켓 기록 |
| 효과 | 공격자 `.11` 403, `normal`은 200이고 **같은 계정으로 정상 로그인 200**(계정 주인은 피해 없음) |
| 원복 | `haedam-50`: 포털 해제 → 공격자 200, 티켓 `restored` |

## 실행

```powershell
python lab/run_ticket.py S1 --restore
```

기대: `input.statuses` 401×9, `effect.normal_login_same_user` `[200]`, `restore.attacker_after` `"200"`.
